Flutter 控制台重构

Flutter 源码位于 flutter_dashboard/，Web 构建产物会输出到 artifacts/flutter_dashboard_web/。

返回控制台

本机运行步骤

cd flutter_dashboard
flutter pub get
flutter run -d chrome

当前环境未检测到 Flutter SDK，请先在本机安装后再运行。

同步到 Django 静态目录

./scripts/build_flutter_dashboard.sh

不要直接修改 artifacts/flutter_dashboard_web/，它是 Flutter Web 的构建产物。
